## Возможности

- Банлист, муты/гаги, админлист, список серверов онлайн
- Веб-RCON, кик/бан из мониторинга игроков
- Админы, группы, серверные флаги SourceMod, overrides
- Протесты и предложения банов, кастомные причины
- Уведомления, системный лог, SMTP
- SEO: `sitemap.xml`, `robots.txt`, Open Graph-обложка
- Антифрод LinkedAccounts через PARSEC API (`api.sibnet-software.ru`)
- Встроенный установщик с проверкой требований и автоочисткой `install/`

## Требования

См. [`requirements.txt`](requirements.txt).

Кратко:

| | Минимум | Рекомендуется |
|---|---|---|
| PHP | 7.1 | **7.1.33** (на 8.x не рассчитана) |
| MySQL / MariaDB | 5.0 | 5.5+ / 10.x |
| Расширения | mysqli, bcmath, xml, json, mbstring, openssl, curl | gd, gmp |

Нужны права на запись: `demos/`, `themes_c/`, `data/`, `config.php` (или корень сайта).

## Установка

1. Залей файлы в document root веб-сервера  
2. Создай пустую БД MySQL/MariaDB  
3. Открой `/install/` и пройди мастер  
4. Удали `install/` (кнопка на финише)  
5. При необходимости пропиши `STEAMAPIKEY` в `config.php`

Проверка без браузера:

```bash
php install/dry_run.php
```

## Обновление файлов (без updater)

Встроенный updater **не нужен** и часто ломает голову. Обновляй так — вручную по FTP/SFTP/файловому менеджеру хостинга.

### 1. Бэкап

Перед любым обновлением скопируй куда-нибудь:

- `config.php`
- `data/` (если есть `data/db.php` и прочее)
- папку с демо (`demos/`), свои карты (`images/maps/`), кастомные картинки
- дамп MySQL (phpMyAdmin → экспорт)

Без бэкапа претензии «ничего не работает» не принимаются.

### 2. Скачай новую сборку

Свежий релиз / ZIP с ветки `main`:  
https://github.com/LapplandBro/blue-material-admin

Распакуй **локально**, не поверх живого сайта сразу.

### 3. Что НЕ затирать на сервере

Эти файлы/папки трогать нельзя (или только если осознанно):

| Путь | Почему |
|---|---|
| `config.php` | ключи, БД, Steam API, настройки сайта |
| `data/db.php` (и весь `data/`) | доступы к БД |
| `demos/` | загруженные демо |
| `themes_c/` | кеш Smarty (можно очистить, см. ниже) |
| `images/maps/` | свои превью карт |
| `images/games/` (если правил вручную) | старые иконки модов |
| свои правки в `images/` (лого, og-cover и т.п.) | кастом |
| `install/` | на рабочей панели папки быть не должно |

Не заливай заново `install/` на прод. Не запускай установщик поверх рабочей БД.

### 4. Что заливать поверх

Из новой сборки залей **с заменой** типично:

- `includes/`
- `pages/`
- `scripts/`
- `themes/new_box/` (тема)
- `images/icons/` (системные SVG-иконки)
- `errors/` (если есть)
- корневые `*.php` (`index.php`, `steam_auth.php`, `init.php`, …) — **кроме** `config.php`
- `.htaccess` — только если не делал своих правок; иначе сравни вручную

Имеет смысл заливать целиком каталоги из списка, а не выборочные файлы «на глаз» — так меньше шансов оставить старый косяк.

### 5. После заливки

1. Очисти кеш шаблонов: удали файлы внутри `themes_c/` (саму папку оставь, права на запись сохрани).  
2. Обнови страницу с полным сбросом кеша браузера (Ctrl+F5).  
3. Зайди в панель под админом, глянь главную / банлист / админку.  
4. Если что-то белое/500 — смотри лог PHP хостинга и что не затёр ли `config.php`.

### 6. База данных

Обычное обновление файлов **не требует** повторного install и не трогает таблицы.  
Если в релизе явно написано «нужна SQL-миграция» — выполни только указанный SQL в phpMyAdmin. Иначе БД не трогай.

### 7. Если всё сломалось

1. Верни из бэкапа `config.php` и `data/`.  
2. Верни предыдущую копию файлов панели.  
3. Не пиши автору «после обновления ничего не работает» без: версии PHP, что именно заливал, текста ошибки из лога.

Целевая PHP по-прежнему **7.1.33**. На PHP 8.x панель не рассчитана — это не баг обновления.
